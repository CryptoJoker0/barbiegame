# BarbieBeast: Battle Arena V1

A playable browser-based fighting-game demo for the BarbieFun ecosystem.

## Included

- Player vs Computer
- Two-player local mode
- Six fictional fighters
- Character selection
- Movement, jumping and crouching
- Blocking
- Light and heavy attacks
- Special attacks and energy meter
- Basic combo counter
- Health bars and timer
- Knockout result screen
- Responsive mobile controls
- Web Audio generated effects
- No wallet or blockchain dependency

## Run

### Easiest
Open `index.html` in a modern browser.

### Local server
```bash
cd barbiebeast-battle-arena
python3 -m http.server 8000
```

Then open:

`http://localhost:8000`

## Controls

### Player 1
- A / D = move
- W = jump
- S = crouch
- J = light attack
- K = heavy attack
- L = special attack
- U = block

### Player 2
- Left / Right Arrow = move
- Up Arrow = jump
- Down Arrow = crouch
- Numpad 1 = light
- Numpad 2 = heavy
- Numpad 3 = special
- Numpad 4 = block
